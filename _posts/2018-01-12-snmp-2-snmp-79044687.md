### Linux

#### 安装

在很多linux系统都有安装此服务, 这里展示如何安装(在终端):

```
yum install net-snmp
yum install net-snmp-libs
yum install net-snmp-utils
service snmpd start
```

创建一个SNMP V3的账户:

```
service snmpd stop
net-snmp-create-v3-user -ro -A TestAuth -X TestPriv -a MD5 -x DES testUser
service snmpd start
```

#### 使用

1. Get 某个OID 的值

获取系统当前运行了多久时间:

snmp v2:

```
snmpget -v 2c -c public 127.0.0.1 1.3.6.1.2.1.1.3.0
```

![]({{ '/assets/images/posts/snmp-2-snmp-79044687/img-006.png' | relative_url }})

snmp v3:

```
snmpget -v 3 -u testUser -a MD5 -A "TestAuth" -X "TestPriv" -x DES -l authPriv 127.0.0.1 1.3.6.1.2.1.1.3.0
```

![]({{ '/assets/images/posts/snmp-2-snmp-79044687/img-007.png' | relative_url }})

2. Walk 某个OID

比如查询当前系统的所有网卡:

使用GETNEXT方式的:

```
snmpwalk -v 3 -u testUser -a MD5 -A "TestAuth" -X "TestPriv" -x DES -l authPriv 127.0.0.1 1.3.6.1.2.1.2.2.1.2
```

使用GETBULK方式的:

```
snmpbulkwalk -v 3 -u testUser -a MD5 -A "TestAuth" -X "TestPriv" -x DES -l authPriv 127.0.0.1 1.3.6.1.2.1.2.2.1.2
```

![]({{ '/assets/images/posts/snmp-2-snmp-79044687/img-008.png' | relative_url }})
