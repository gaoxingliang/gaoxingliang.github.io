#### 1. Linux中查询某个域名的ipv6地址:

```
nslookup -query=AAAA betax.cc
```

![]({{ '/assets/images/posts/dns-ipv6-79097683/img-001.png' | relative_url }})
  

#### 2. Windows中查询某个域名的ipv6地址:

```
nslookup -q=AAAA betax.cc
```

![]({{ '/assets/images/posts/dns-ipv6-79097683/img-002.png' | relative_url }})
  

#### 3. Java/Groovy中根据域名获取IPv6的实现:

[1]调用getAll会获取所有的地址:

```
for (InetAddress i : InetAddress.getAllByName("betax.cc")) {
    println i
}
```

[2]最终会调用Native方法:

![]({{ '/assets/images/posts/dns-ipv6-79097683/img-003.png' | relative_url }})  
[3]该Native方法的源码在: src/windows/native/java/net/Inet6AddressImpl.c#Java\_java\_net\_Inet6AddressImpl\_lookupAllHostAddr

![]({{ '/assets/images/posts/dns-ipv6-79097683/img-004.png' | relative_url }})

[4]该方法中调用了系统函数getaddrinfo - Linux: 
<http://man7.org/linux/man-pages/man3/getaddrinfo.3.html>

Windows:
 [https://msdn.microsoft.com/en-us/library/windows/desktop/ms738520(v=vs.85).aspx](https://msdn.microsoft.com/en-us/library/windows/desktop/ms738520%28v=vs.85%29.aspx)

该函数会返回所有的IP地址, 然后根据是否preferIPv6 or preferIPv4 来决定返回顺序.

#### 4. Windows 或者 linux 如果想正确解析出IPv6的地址

 你本地**必须**拥有一个IPv6地址, windows添加IPv6地址可以用这个 - http://blog.csdn.net/ssergsw/article/details/9125813
