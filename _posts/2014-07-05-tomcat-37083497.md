首先需要下载tomcat的源码，然后创建一个java project 导入tomcat源代码

像下图：到如下层级：C:\Users\Administrator\Downloads\apache-tomcat-7.0.47-src\apache-tomcat-7.0.47-src\java

![]()![]({{ '/assets/images/posts/tomcat-37083497/img-002.png' | relative_url }})

然后修改tomcat/bin/startup.bat

添加如下：suspend=y 就可以调试tomcat启动过程。

SET CATALINA\_OPTS=-server -Xdebug -Xnoagent -Djava.compiler=NONE -Xrunjdwp:transport=dt\_socket,server=y,suspend=y,address=8788

![]({{ '/assets/images/posts/tomcat-37083497/img-003.png' | relative_url }})

打开你想调试的tomcat源码：

eclipse

![]({{ '/assets/images/posts/tomcat-37083497/img-004.png' | relative_url }})

然后启动就可以看见调试的代码了。

![]({{ '/assets/images/posts/tomcat-37083497/img-005.png' | relative_url }})

	public static void main(String[] args) throws Exception {

		System.out.println(file2.substring(10));
		ZipFile zf = new ZipFile(file2, "utf-8");

			System.out.println(e.nextElement());
		}
